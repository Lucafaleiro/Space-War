🚀 Space War

Space War é um jogo de batalha espacial desenvolvido na plataforma Construct 3, onde você assume o comando de uma nave para enfrentar uma invasão alienígena. Prepare-se para uma experiência dinâmica e cheia de ação, com uma trilha sonora impactante e combates intensos contra inimigos intergalácticos.

🕹️ Sobre o Jogo

Neste jogo de ação em 2D, sua missão é simples, porém desafiadora: sobreviver e destruir as naves alienígenas que estão atacando você sem piedade. Com gráficos em estilo retrô e um fundo estrelado imersivo, Space War transporta o jogador para o coração de uma guerra espacial.

⚙️ Plataforma e Tecnologias

O jogo foi desenvolvido usando a engine Construct 3, que utiliza tecnologias como:

Folha de eventos

🌌 Conteúdo do Jogo

🚀 Nave controlável: Você é o piloto!

👾 Inimigos alienígenas: Ataques constantes e movimentação agressiva.

🌠 Fundo estrelado: Ambienta a guerra no espaço profundo.

🎵 Trilha sonora impactante: Adiciona emoção e ritmo ao combate.

📦 Requisitos

Navegador compatível com HTML5 (Google Chrome, Firefox, Edge, etc.)

Mouse e teclado
